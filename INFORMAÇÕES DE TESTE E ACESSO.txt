1) Para criar uma tabela com os seguintes dados:

CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    born_date DATE NOT NULL,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

2) Para inserir dados na tabela users utilize o comando abaixo:

INSERT INTO users (username, email, born_date, password) VALUES
('ValquimarSantos', 'santos2345@discente.ufg.br', '1981-07-26', '202108415'),
('mariacosta', 'maria@email.com', '2000-07-22', '654321'),
('pedroalves', 'pedro@email.com', '1998-11-10', 'senha123');


3) Para visualizar o que você criou acima, utilize o código a seguir:
SELECT * FROM users;
